새 CCM 멜로디 연습 (new-ccm)

ccm 프로그램과 똑같은 프로그램입니다. 다른 점은 두 가지뿐입니다.
- 곡: 이 폴더의 songs 폴더에 따로 들어 있습니다 (번호도 1번부터 따로).
- 브라우저 저장 이름표: ccm은 'ccm…', 새 CCM은 'nccm…'을 써서
  가사·곡별 설정·예약 목록이 ccm과 섞이지 않습니다. (글꼴 같은 공통 설정도 따로)

폴더 구성
  index.html, list.html, player.html, abcjs-basic-min.js  ← ccm과 같은 프로그램 파일
  songs/index.js                                          ← 곡 목록
  songs/번호.js                                           ← 곡 악보

프로그램을 고칠 때
  ccm의 index.html·list.html·player.html을 고치면, 이름표만 바꿔 new-ccm용을 다시 만듭니다.
  (songs 폴더는 건드리지 않음)

곡 추가
  songs/번호.js 를 만들고 songs/index.js 에 한 줄 추가합니다. 형식은 ccm과 같습니다.

되돌이표를 풀어 쓴 곡
  3번 은혜, 4번 충만은 되돌이표(1·2번 괄호)를 풀어서 처음부터 끝까지 한 줄로 썼습니다.
  가사는 부르는 순서대로 이어서 입력하면 됩니다.
  - 은혜: 1절 칸 = '내가 누려왔던 …(첫 번째)' + '아침 해가 뜨고 …(두 번째)', 2절 칸도 같은 방식, 후렴 칸 = '모든 것이 은혜 …'
  - 충만: 1절 칸 하나에 처음부터 끝까지

※ 가사·악보는 개인 연습용입니다. 공개 웹에 올리지 마세요.
